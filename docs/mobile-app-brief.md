# Nova Mind — Мобайл аппын товч танилцуулга

*2026-07-27 · багийн хэлэлцүүлэгт зориулав*

## Нэг өгүүлбэрээр

Одоогийн вэб системээ хэвээр нь үлдээж, түүний **арын систем дээр тулгуурласан
жинхэнэ native iOS апп**-ыг Expo дээр шинээр бичнэ. Апп нь вэбийн хуулбар биш,
утсан дээр өдөр тутам хэрэгтэй зүйлсэд төвлөрсөн байна.

## Яагаад вэбээ зүгээр л "боож" болохгүй гэж?

Хамгийн хямд арга нь вэбсайтаа аппын бүрхүүлд хийх (PWA/Capacitor). Android
дээр энэ нь ажилласан — AAB файл гарсан. Гэвч iOS дээр Apple-ийн **Guideline
4.2** гэсэн дүрэм байдаг: зүгээр л вэбсайтаа боосон аппыг татгалздаг.

Тэр татгалзлаас зайлсхийхийн тулд push notification, Face ID, камер, календарь,
Home Screen widget зэрэг native функцүүдийг нэмэх шаардлагатай болно. Бид тэр
замын төлөвлөгөөг бичээд дүгнэхэд ийм зураг гарсан:

> Бүх үе шатыг дуусгахад гарт үлдэх зүйл нь **webview + Capacitor plugin-ууд +
> дээр нь хоёр Swift target**. Өөрөөр хэлбэл native ажлыг нь ямар ч байсан
> хийчхээд, Apple-ийн эрсдэлээ бас үүрсэн хэвээр.

Тиймээс тэр замыг орхисон.

**Шинээр бичих нь эрсдэлтэй сонсогдож болох ч энд тийм биш.** Учир нь дахин
бичих зүйл нь **зөвхөн дэлгэцүүд**. Арын систем бүхэлдээ хэвээр үлдэнэ:

| Аль хэдийн бэлэн, хөндөхгүй | Дахин бичигдэнэ |
| --- | --- |
| Хэн юу харах эрхийн шүүлт (сервер тал) | Дэлгэцүүдийн UI |
| Нэвтрэлт, token шалгалт | — |
| Өгөгдлийн сан, схем, seed | — |
| Бизнес логик | — |

## v1-д юу орох вэ

Утсан дээр өдөр бүр нээдэг зүйлс л орно.

| Дүр | Апп дээр |
| --- | --- |
| **Сурагч** | Нүүр (өнөөдрийн хуваарь, сүүлийн дүн) · Хуваарь · Дүн · Ирц · Зарлал · Төлбөр |
| **Эцэг эх** | Сурагчтай ижил, хүүхдийнхээ мэдээллийг харна |
| **Багш** | Нүүр (өнөөдрийн хичээлүүд) · **Ирц бүртгэх** · **Дүн оруулах** · Хуваарь · Зарлал |
| **Админ** | Апп дээр байхгүй — вэб рүү чиглүүлнэ |

Сурагч, эцэг эх зөвхөн уншина. Багш ирц, дүн хоёрыг бичнэ.

**v1-д ороогүй, дараа нэмэгдэнэ:** хичээлийн материал, даалгавар илгээх, файл
татах, push notification, офлайн бичих.

## Админ яагаад вэб дээр үлдэх вэ?

Одоогийн админ хяналтын самбар нь 3,500 гаруй мөр код бүхий, олон баганатай
хүснэгтүүдээс бүрддэг. Үүнийг утасны дэлгэцэд шахах нь ямар аргаар хийсэн ч
хэрэглэхэд эвгүй байна. Админ ажил ширээний компьютер дээр хийгддэг — тэнд нь
үлдээх нь илүү зөв бөгөөс ажлын хэмжээг ч эрс багасгаж байна.

## Хэрхэн ажиллах вэ

```
   iPhone апп  ──HTTPS──▶  Одоогийн Vercel сервер  ──▶  Supabase (нэвтрэлт + өгөгдөл)
   (Expo)                   (шинэ /api/mobile/*)
```

Апп нь одоо байгаа серверт л ханддаг. Түүн дээр мобайлд тохирсон цөөн шинэ
хаяг нэмнэ.

**Хамгийн чухал дүрэм:** шинэ хаягууд өөрсдөө өгөгдлийн сан руу хандахгүй.
Одоо байгаа функцүүдийг дуудаад үр дүнг нь хөрвүүлж өгнө. Ингэснээр "хэн юуг
харах эрхтэй вэ" гэсэн логик ганцхан газар үлдэнэ. Хэрэв хоёр газар салбарлавал
нэг өдөр зөрж, **сурагч өөр сурагчийн дүнг харах** эрсдэл үүснэ. Үүнийг тусгай
шалгалтаар баталгаажуулна.

## Одоогийн явц

Ажил нь хоёр үе шаттай:

**А үе — сервер тал (11 алхам).** Мобайлд зориулсан өгөгдлийн хаягууд. Аппгүйгээр
бүрэн шалгагдана.
Явц: **1 / 11 дууссан.**

**Б үе — Expo апп.** Дэлгэцүүд, нэвтрэлт, навигаци, офлайн.
Явц: эхлээгүй. Төлөвлөгөө нь зориудаар хараахан бичигдээгүй — А үеийн хоёр
техникийн асуулт шийдэгдсэний дараа бичихээр төлөвлөсөн. Эс бөгөөс батлагдаагүй
таамаг дээр төлөвлөх болно.

Хугацааны таамаг зориуд өгөөгүй байгаа. Найдвартай тоо гаргах үндэслэл одоогоор
байхгүй тул хийсэн тоо хэлэхийн оронд үе шатын явцаар мэдээлнэ.

## Багаас шаардагдах зүйлс

Эдгээр нь **кодоос хамаарахгүй**, хугацаа шаарддаг тул одооноос эхлэх нь зүйтэй:

| Зүйл | Тайлбар |
| --- | --- |
| **Apple Developer эрх** | Жилд $99. Батлагдахад хэдэн өдөр |
| **Xcode** | Mac дээр суусан байх |
| `SUPABASE_SERVICE_ROLE_KEY` | Одоо тавигдаагүй. Байхгүй бол админ хэрэглэгч үүсгэх боломжгүй — Apple-ийн шалгагчид өгөх туршилтын эрхийг ч үүсгэж чадахгүй |
| `NEXT_PUBLIC_SITE_URL` | Одоо тавигдаагүй |
| Аппын нэр / bundle ID | `mn.novamind.academy` гэж санал болгож байна |

## Ил тод хэлэх нэг зүйл

Apple-ийн шалгалтыг давна гэсэн **баталгаа байхгүй**. Гэхдээ жинхэнэ native апп
нь боосон вэбсайтаас хамаагүй хүчтэй байр суурьтай. Эрсдэл тэг биш, харин огт
өөр зэрэглэлийн эрсдэл.
